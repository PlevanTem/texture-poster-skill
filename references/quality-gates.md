# 质量门控与失败修正

先暂时忽略文字的加分，让视觉母版逻辑通过五项硬门；图像与排版一体生成后再做完整评分。任一硬门失败时，不用文字、Logo 或装饰掩盖。

## 五项硬门

1. **视觉传达效果**：暂时忽略文字的加分，图像背景已经由裁切、尺度、明暗、色域、材质层次、空间张力和视觉动线形成主动后期美学；不是普通照片、统一滤镜或等待文字补救的背景图。
2. **缩略图**：缩到手机预览，仍只有一个焦点和清晰的大面积明暗关系。
3. **材质不可替换**：随意换成纸、石、金属或水会破坏概念；否则材质命题不成立。
4. **减法**：无需识别原对象时，照片已明显舍弃或重组约 50%–70% 的环境信息。
5. **真实性**：材质具有尺度、方向、光线、粗糙度和空间深度，不是噪点、平铺贴图或塑料 CGI。

## 完整海报评分

| 维度 | 权重 | 通过标准 |
| --- | ---: | --- |
| 主题—材质关系 | 20 | 材质物理属性直接表达概念，不能被随意替换 |
| 材质主体化 | 15 | 先感到表面，再识别物体 |
| 抽象转译 | 15 | 输入被裁切、放大或重组，摆脱普通摄影语境 |
| 编辑精调 | 15 | 反差、纹理尺度、方向、光线和景深被选择性控制 |
| 减法与焦点 | 15 | 一个主关系、一个焦点、一个实验动作 |
| 图形/摄影/排版整合 | 10 | 字体与装饰的颜色、尺度和位置匹配母版并回应视觉重心，共同传达概念 |
| 色彩与光线统一 | 5 | 颜色来自材质，光线揭示表面 |
| 独特性与必要性 | 5 | 至少一个决定不能由通用模板替代 |

低于 70 不交付；70–79 仅作方向稿；80 以上且无硬门失败才是完成稿。

## 失败诊断

| 表现 | 原因 | 单一修正动作 |
| --- | --- | --- |
| 普通照片加噪点 | 材质未主体化 | 放大材质尺度并删除更多叙事物件 |
| 像廉价复古模板 | 做旧覆盖所有元素 | 保留图像粗粝，恢复排版干净边缘 |
| 通用黑金奢侈品感 | 材质只承担装饰 | 回到概念，改选有物理因果的材质 |
| 多个焦点争抢 | 实验动作过多 | 只留一个接触关系和一个失序点 |
| 出现网格与辅助线 | 把组织方法当成元素 | 删除所有可见脚手架，只保留对齐结果 |
| 肌理平且重复 | 平铺贴图 | 增加尺度差、方向光、景深和局部遮挡 |
| CGI 塑料感 | 表面过度光滑 | 增加真实粗糙度、反射衰减和不规则边缘 |
| 实验字实为乱码 | 一体生成后未校验字形与文案 | 保持既定图文关系，局部重做文字区域或用真实字体精确替换 |

## 交付清单

- 是一张海报，不是九宫格、情绪板或联系表。
- 主材质、唯一焦点和概念关系在缩略图成立。
- 字体、字重与颜色匹配母版；文字位置、大小和对齐回应视觉重心；装饰元素具有结构功能；没有可见网格。
- 文案逐字准确，使用真实字体，没有伪 Logo、乱码或无意义微型字。
- 没有复制风格板的品牌、文字、签名或具体图像。
- 来源、模型补充内容、低清限制和权利状态已记录。
