# 生成前创意简报

每个方案一份，只填写会改变生成决策的内容。简报不是写给观众看的文案，也不是把风格词堆成提示词。

```text

主题 / 品牌 / 对象：
必须逐字准确 / 可选 / 禁止出现：

来源：
- Image 1 路径 / 角色 / 来源页 / 访问日期 / 权利状态：
- Image 2：<skill>/assets/reference.png，仅作风格板
- Image 3+ 路径 / 允许使用的事实：

照片直接可见：

未知或不得进入海报：

概念动词：

主材质 / 辅助材质：
保留的 2–3 个材质事实：

必须保留的身份锚点（如有）：

标题 / 副标题 / 元信息：

```

## 简报成立的三个判断

1. 材质命题不是“因为好看”，而是物理属性与主题之间存在可解释关系。
2. 删除清单比保留清单长；否则很容易退化成原图调色。
3. 不看文字，裁切、明暗、比例、材质和空间关系仍然有主动设计。
